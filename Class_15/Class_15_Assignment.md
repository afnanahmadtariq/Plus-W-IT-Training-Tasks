# 🛠️ Assignment 15 — Linux System Tools & Text Processing

This repository contains the solution and documentation for **Assignment 15:** *Linux System Administration & DevOps Tools* .

## 📑 Assignment Overview

The objective of this assignment is to simulate real-world Linux system administrator tasks, including:

- Setting up user and group permissions
- Running real-time network and system diagnostics
- Archiving and compressing directories
- Extracting meaningful data from system logs using `grep` and `awk`

## 🏢 Industry Scenario

You're working as a junior system administrator at **CloudOps Ltd.** Your manager has assigned you the following:

1. Create users and groups for the networking team.
2. Perform real-time network diagnostics.
3. Backup log data using compression tools.
4. Analyze logs with text processing utilities.

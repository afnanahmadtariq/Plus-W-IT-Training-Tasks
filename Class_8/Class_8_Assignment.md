## 📌 Assignments

### 1️⃣ Sales Forecasting for a Retail Store
**Objective:**
- Predict retail sales based on advertisement budget, discount rate, season, and store traffic.
- Train a linear regression model and evaluate its performance.

**File:** [Sales Forecasting](./Assignment_Tasks/Sales_Forecasting.ipynb)

### 2️⃣ Email Spam Detection using SVM
**Objective:**
- Classify emails as spam or ham using text classification and SVM.
- Use TF-IDF for text vectorization and preprocess data effectively.

**File:** [Email Spam Detection](./Assignment_Tasks/Email_Spam_Detection.ipynb)

**Objective:**

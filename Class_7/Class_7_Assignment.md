## 📌 Assignments

### 1️⃣ House Price Prediction System
**Objective:**
- Build a model that predicts house prices based on features like square footage, number of bedrooms, location, and age of the house.
- Apply linear regression using Ordinary Least Squares (OLS) and evaluate using R-squared and Adjusted R-squared.
- Handle missing values and perform categorical encoding.

**File:** [House Price Prediction System](./Assignment_Tasks/House_Price_Prediction_System.ipynb)

---

### 2️⃣ Salary Prediction System
**Objective:**
- Develop a system that predicts employee salary based on experience, education, job role, and location.
- Implement linear regression and tune the model.
- Visualize the regression line and evaluate model performance.
- Create a simple web app for user input and predictions.

**File:** [Salary Prediction System](./Assignment_Tasks/Salary_Prediction_System.ipynb)

---

### 3️⃣ Stock Price Trend Prediction
**Objective:**
- Predict the future closing price of a stock based on past stock prices, volume, and market trends.
- Use Yahoo Finance API to fetch stock data.
- Apply a linear regression model for short-term predictions.
- Visualize stock price trends and display predictions on a Streamlit dashboard.

**File:** [Stock Price Trend Prediction](./Assignment_Tasks/Stock_Price_Trend_Prediction.ipynb)

---

### 4️⃣ Customer Churn Prediction for a Subscription Service
**Objective:**
- Predict whether a customer will continue their subscription or churn based on engagement, billing issues, and support interactions.
- Apply logistic regression for classification.
- Optimize the model and evaluate accuracy using a confusion matrix.
- Create an alert system for potential churners.

**File:** [Customer Churn Prediction](./Assignment_Tasks/Customer_Churn_Prediction.ipynb)

---

### 5️⃣ Energy Consumption Prediction
**Objective:**
- Predict household energy consumption based on temperature, appliance usage, and seasonal variations.
- Train a linear regression model with time-based features.
- Optimize the model with Gradient Descent.
- Deploy a dashboard to visualize energy usage trends.

**File:** [Energy Consumption Prediction](./Assignment_Tasks/Energy_Consumption_Prediction.ipynb)
